# DSH 插件面板 · UI/布局重构方案（阶段一：结构与排版定稿稿）

> 状态：**待用户确认结构**。确认后 → 阶段二出单文件 HTML 高保真设计图 → 阶段三改代码。
> 输入（用户 2026-09-30 裁定）：面板约占屏宽 **1/3**（→ 实宽约 520–850px）；最高频仅三件事（**发消息/插队、切换会话、看 agent 在干什么**）；管理面**留在面板内**；状态胶囊**常显摘要、点击展开**；**输出内容要重排、更易读**；**会话内容不要点赞/点踩**。

---

## 1. 设计原则（第一性原理，不带历史包袱）

1. **纵向空间只给主任务**：滚动区（读到的东西）与输入区（要发的东西）是唯一允许"常驻占高"的两块。其余一切（导航、状态、管理）都必须**零常驻成本**或**一条摘要**。
2. **一个容器，多个域**：管理动作不再散成 9 个同质抽屉，而是**一个抽屉 + 域 tab**；用户建立"去哪里找东西"的空间记忆。
3. **状态合一**：goal / 待发 / 上下文 / 轮次统计本质是同一件事（这个会话现在什么状态）⇒ 合并成**一条胶囊**，展开才看详情，展开用**浮层**（不挤压画布）。
4. **动作跟随语义**：跟"发送"有关的（模型、预设、引用、附件）放输入区；跟"查看"有关的放抽屉；跟"切换"有关的放标题。
5. **密度分级**：正文（读）要松；列表/表格（扫）要紧；控件（点）要够大（≥24px 命中区）。
6. **可退化**：窄档不牺牲功能，只改呈现（图标化、浮层化）。

## 2. 骨架与断点

### 2.1 宽档（面板 ≥ 760px，1/3 屏时常见）

```
┌──────────────────────────────────────────────────────────────────────┐
│ ●  会话标题 ⌄        ◎目标 · 2待发 · 62%上下文          ⌕  ⋯        │ 28px 头部（唯一常驻行）
├───────────────────────────────────────────────────┬──────────────────┤
│                                                   │  抽屉（停靠）    │
│                  画布（滚动）                      │  ┌────────────┐  │
│                                                   │  │会话 运行    │  │
│  ┌ 你 ────────────────────────────────┐           │  │设置 帮助    │  │
│  │ 用户消息（右对齐，最大 76%）        │           │  ├────────────┤  │
│  └────────────────────────────────────┘           │  │            │  │
│                                                   │  │  域内容     │  │
│  助手输出（左对齐，全宽，排版见 §4）                │  │            │  │
│  ▸ 工具组 · 4 步 · 12.3s            （折叠单行）    │  │            │  │
│  ▸ 本轮产出 · 3 文件                （折叠单行）    │  │            │  │
│                                                   │  └────────────┘  │
├───────────────────────────────────────────────────┴──────────────────┤
│ ⇥ 2 条待发：第一条…（点击展开）                        [全部插队]      │ 仅当有待发（0 行=不占）
├──────────────────────────────────────────────────────────────────────┤
│ 输入…                                                     [@][+][/]   │
│                                                    [模型⌄] [ 发送 ]  │ 输入区
└──────────────────────────────────────────────────────────────────────┘
```

### 2.2 中档（520–760px）

抽屉改为**覆盖式**（宽 420px，画布变暗 20%），其余同宽档；头部右端由 `⌕ ⋯` 变为 `⌕ ⋯`（不变），胶囊自动缩短为 `◎ · 2 · 62%`。

### 2.3 窄档（< 520px）

```
┌────────────────────────────────────────┐
│ ● 标题 ⌄              ◎2 62%      ⋯   │
├────────────────────────────────────────┤
│              画布（滚动）               │
├────────────────────────────────────────┤
│ ⇥ 2 条待发                              │
├────────────────────────────────────────┤
│ 输入…                          [+] [↑] │
└────────────────────────────────────────┘
```
抽屉全屏覆盖；模型/预设/引用收进 `[+]`；待发条仍保留一行（它是**动作**，不是状态）。

## 3. 组件职责表

| 区域 | 内容 | 规则 |
|---|---|---|
| **头部（1 行）** | 连接点 · 会话标题⌄ · 状态胶囊 · 搜索 · ⋯ | 点标题 = 打开抽屉「会话」tab（**不再有并列的"工作区"入口**，工作区成为该 tab 内的分组）；`⌕` = 跨会话搜索浮层；`⋯` = 分域溢出菜单（带文字标签，不是裸图标） |
| **状态胶囊** | `◎目标 · N待发 · 上下文%`（无某段则省略） | 常显**摘要**；点击 → **浮层**展开详情（goal 操作按钮、待发明细、token/轮次统计、上下文档位）；无 goal 时摘要只显示 `◎ 设目标` 微型动作，**不再占整行** |
| **抽屉（一个容器）** | tab：`会话`（列表/搜索/工作区/提醒/产出）· `运行`（任务/子代理/轨迹）· `设置` · `帮助` | 记住上次 tab；≥760px 可停靠并排，否则覆盖；宽度可拖；`Esc` 关闭 |
| **待发条** | 仅当天有待发消息 | 1 行摘要 + `[全部插队]`；点开进抽屉「运行」明细；为 0 时**完全不占高** |
| **输入区** | 多行输入 + `@引用`/`+附件`/`/命令` + `模型⌄` + 发送 | 模型与预设**从顶部下沉**到此处（它们属于"发送"）；`Enter` 发送、`Shift+Enter` 换行保持 |
| **画布** | 用户消息 / 助手输出 / 工具组 / 产出卡 / 分隔线 | 见 §4；**移除点赞点踩**；保留复制、（可选）从此处分叉 |

## 4. 输出区排版规则（可读性优先）

目标：**一屏（800px 高）看到 ≥30 行正文**（现状约 22 行），同时"更好看"来自**层级与节奏**，不来自装饰。

| 元素 | 规则 |
|---|---|
| 正文 | 14px / 行高 22px（本体成对值）/ 段间距 10px；不加左右边距浪费，正文满宽 |
| 标题 | H1→18/26、H2→16/24、H3→14.5/22、H4→14/22；**靠字号+粗体+上间距（12px）区分**，不用横线 |
| 列表 | 项间距 4px、缩进 16px、序号等宽数字；嵌套最多两级后改小圆点 |
| 代码 | 12.5px / 行高 20px / 左右各 8px 内边距；语言标签右上角淡显；横向滚动不折行；**复制按钮 hover 出现** |
| 表格 | 12.5px / 行高 20px；表头 11.5px + 淡背景 + 不加粗大写；行间 1px 分隔线；首列不折行（超长省略 + title） |
| 引用/标注 | 左 2px 竖线 + 淡背景 + 内边距 8px；不倾斜 |
| **工具活动** | **同一轮连续工具合并为一个"工具组"单行**：`▸ 工具组 · 4 步 · 12.3s`（图标+名称+状态+耗时）；点开才展开每步。**这是当前"密"的最大来源**（现为每步一张卡） |
| 产出文件 | 单行折叠：`▸ 本轮产出 · 3 文件`；点开列出，点击开文件/变更 |
| 用户消息 | 右对齐、最大宽 76%、13.5px、圆角 10px；**不再显示"你"的 role 行**（气泡本身已表明） |
| 助手消息 | 左对齐，**不显示 role 行**；靠"无气泡 + 左侧一条 2px 淡竖线"区分（省一行/条） |
| 分隔与统计 | 回合分隔线细化（`— · 第 N 轮 · 3.2s` 一行居中淡显，替代现在的多条统计/状态行） |
| 阅读动效 | 不做打字机（会与"内容整段到达"的 0.2.0 现实冲突）；改为**新内容淡入 120ms** |

## 5. 会话区（列表/导航）优化

1. **分组**：按工作区分组（可折叠），组内 **置顶优先**；当前会话左侧 2px 强调条。
2. **行结构（单行，14px 高密度）**：`● 标题 ··············· 相对时间 · [运行时徽标] · [hover: 📌 ✎ ⋯]`；未读=左侧小点，运行中=绿色脉冲点。
3. **筛选条**：`全部 / 运行中 / 置顶 / 归档` 四个 chip + 搜索框（**输入即跨工作区过滤**，沿用现有的宿主侧按需过滤）。
4. **归档**：默认隐藏；chip 切到"归档"才显示，行内直接"取消归档"。
5. 移除：每行 3 个常驻图标按钮（现在 hover 才出现，但一行仍显乱）→ 保留 1 个 `⋯`（菜单：重命名/置顶/归档/分叉/移动组）。

---

## 6. 明确移除

- **助手消息的 👍/👎**：按用户要求移除（消息反馈接口暂不接）。
- 顶部 8 个常驻图标按钮 → 收进 `⋯`。
- 独立占行的 GoalBar → 并入状态胶囊。
- role 行（"你"/"助手"）、部分统计行、上下文独立条 → 合并/移除。
